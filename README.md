# Telemedicine Appointment System

Телемедицина ақпараттық жүйесі пациенттерге дәрігерге онлайн жазылуға, электронды медициналық картасын көруге және қабылдау туралы еске салулар алуға мүмкіндік береді. Жоба клиникаға бару қажеттілігін азайтады және дәрігерлер мен пациенттердің жұмысын жүйелейді. Жүйе пациенттерге, дәрігерлерге және тіркеу бөлімінің қызметкерлеріне арналған.

## Мақсаты
Дәрігер қабылдауына онлайн жазылуды, электронды картаны жүргізуді және еске салуларды бір жүйеде автоматтандыру.

## Пайдаланушылар
- Пациент
- Дәрігер
- Тіркеу бөлімінің қызметкері (регистратор)
- Әкімші

## Талаптар
1. Пациент жүйеге тіркеліп, жеке кабинетіне кіреді.
2. Пациент дәрігерді мамандығы бойынша таңдап, бос уақытты қарайды.
3. Пациент таңдалған дәрігердің бос уақытына қабылдауға жазылады немесе жазылуды бас тартады.
4. Дәрігер өз кестесін көреді және қабылдауды бейнеқоңырау арқылы өткізеді.
5. Дәрігер қабылдау нәтижесін (диагноз, тағайындау) пациенттің электронды картасына жазады.
6. Пациент өзінің электронды картасын және қабылдау тарихын көреді.
7. Жүйе қабылдауға дейін пациентке еске салу жібереді (email/SMS).
8. Әкімші дәрігерлер тізімін және олардың жұмыс кестесін басқарады.
